# 素材来源登记表

> **这个文件是干什么的**
>
> 站上每一张插画都必须在这里登记一行。`npm run content:index` 会读这张表生成
> 「素材来源」页（`/credits`）。如果某张图没登记，构建不会失败，但页面上就不会出现它——
> 所以换图之后记得回来加一行。
>
> **表格格式**：第一行必须是表头，列的顺序随意，但列名要一致：
>
> | 文件名 | 作品名 | 作者 | 出处 | 许可 | 获取日期 | 级别 | 备注 |
>
> **级别怎么填**
>
> - `A` —— 明确可商用/可自由使用（CC0、CC BY、明确授权）
> - `B` —— 需要署名（CC BY、CC BY-SA 等），已在「作者」列写明
> - `C` —— 来源为同人/官方图的二次传播，版权归属原权利方，仅个人非商业展示
>
> 本站目前所有插画均为 `C` 级：个人非商业展示，不提供转载或商用授权。
> 如你是权利方且不希望作品出现在这里，请通过仓库 Issues 联系下架。

## 怎么加一条

1. 把图片放进 `public/art/`（或 `public/art/posts/`、`public/gallery/`）
2. 在下面表格末尾加一行，`文件名` 列写**相对于 public 的路径**，不要带开头的 `/`
   - 例：`art/posts/新文章.webp`
3. 保存，然后跑 `npm run content:index`
4. 打开 `/credits` 页确认新的一行出现了

> 表头不要动。分隔行 `|---|---|` 那一行也不要动，脚本靠它区分表头和内容。
