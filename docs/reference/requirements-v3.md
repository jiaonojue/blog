| 音效 | **无** |
| 加载 | 三种策略可选：`minimal`（细线进度）/ `illustration`（插画小幅呼吸动画）/ `off`。默认 `minimal`，仅当导航等待 > 300ms 才显示，最长 600ms 强制消失 |
| 减少动效 | 必须同时支持：系统 `prefers-reduced-motion` 自动降级 + 站内开关。降级后：视差关闭、光斑关闭、拖尾关闭、粒子关闭、转场改为 120ms 淡入、滚动入场改为直接显示 |

### 3.5 素材获取与插画管线

#### 3.5.1 职责边界

| 角色 | 负责 |
|---|---|
| **agent** | 按 brief 检索 → 筛选 → 校验许可 → 下载 → 压缩转码 → 落位 → 登记 → 渲染校验。**六类坑位全部由你填满** |
| **我** | 不满意时用同名文件覆盖；或把自己找的图放进 `public/art/`、`local-art/`。这是**覆盖入口**，不是**兜底方案** |
| **共同** | 素材一经落位，无论来源，都必须进 `CREDITS.md` |

**硬性要求**：P2 交付时，`public/art/` 与所有内容封面目录下**不得存在任何占位图**，只能存在有来源登记的成品图。

#### 3.5.2 源分级

| 级别 | 源 | agent 的动作 |
|---|---|---|
| **A｜直采** | Pixabay、Pexels、Unsplash、いらすとや（CC0 系列）、Wikimedia Commons（PD/CC0）、Openverse、Rawpixel 免费区 | 可直接下载、落位、部署，无需署名的也要登记来源 |
| **B｜署名采** | CC-BY 系列（Wikimedia、Flickr CC-BY、部分 Openverse 结果） | 可下载部署，但 `CREDITS.md` 必须含作者、许可版本、许可链接，`/credits` 页可点达 |
| **C｜清单采** | **pixiv**、X/Twitter、微博、小红书、番剧官方截图、动画/游戏官方立绘、画师个人站 | **禁止抓取**。产出一份「采集清单」，字段见 3.5.7；我下载后放入目录，你接线、压图、登记、校验 |

补充规则：
- 不确定许可的图，一律按 C 级处理，不许"先用了再说"。
- 同一坑位若 A 级源找不到达标图，**必须先去 B 级找**，再降到 C 级出清单，不许直接跳到"用占位图"。
- C 级清单每坑位至少给 **3 个候选**，标注推荐度、理由、建议裁剪区域。

#### 3.5.3 坑位清单与 art brief

按此表检索，**不许按"随便找张好看的"执行**。

| 坑位 | 尺寸 | 构图要求 | 色调 | 检索关键词（中/英/日） |
|---|---|---|---|---|
| `art/hero.webp` | 2400×1400 | 左侧 40% 或底部 30% 必须低信息低对比（供文字叠加）；主体偏右或偏上 | 暖粉 + 青蓝，柔光 | 日系 天空 窗边 / anime sky window / 夕焼け 部屋 |
| `art/about.webp` | 1200×1200 | 方形中心构图，桌面/窗台/静物，右上留出气泡位 | 奶油白底，暖光 | 日系 桌面 静物 / cozy desk still life / 机の上 小物 |
| `art/og-default.png` | 1200×630 | 可由 hero 裁切，须保证主体完整 | 同 hero | — |
| `art/og-posts.png`、`art/og-favorites.png` | 1200×630 | 同源图不同裁切，或统一排版封面 | 与分区色呼应 | — |

#### 3.5.4 质量门槛（不达标就换，不许凑数）

1. 长边 ≥ 目标尺寸，放大到实际显示尺寸不糊。
2. 主视觉的文字叠加区必须是低信息区；叠上白色大标题后仍可读。
3. 色调落在 tokens 的暖粉—青蓝区间；偏灰、偏绿、强饱和红**直接淘汰**。
4. 无文字、无水印、无 logo、无平台角标、无压缩伪影。
5. 与噪点层（`opacity .04`）叠加后不过曝、不脏。
6. 375px 宽下裁切后主体仍在画面内，必须验证 `object-position`。
7. 同一页面内的多张图，光源方向与色温要一致。
8. **宁可留白，不要放一张不合适的图**：某坑位连续 3 轮未达标，改用 CSS 渐变 + SVG 抽象构图（几何 + 噪点 + 印章），并在 HANDOVER 注明原因与后续替换建议。

#### 3.5.5 版权敏感坑位的替代设计

| 坑位 | 禁止 | 替代方案 |
|---|---|---|
| 番剧感想文章封面 | 动画截图、官方宣传图 | 氛围图（A 级）+ 底部压标题条；或 `scripts/gen-covers.mjs` 生成的排版封面（标题 + 集数 + 印章 + 主题色块） |
| 收藏卡番剧/游戏封面 | 官方海报、官方立绘 | **统一排版封面**：作品名 + 类型色带 + 评分 + 印章，8 张卡视觉一致 |
| 音乐 / 书 | 专辑封面、书封 | 纯排版条目行（无图），靠 Space Grotesk 的排版撑住 |
| 相册 | 任何 B / C 级源 | 只用 A 级或我自备 |

> 这不是妥协，是设计决策：**封面风格统一，比封面"真实"更能提高整站质感。**

#### 3.5.6 人物规则

- 插画**可以**出现二次元人物，但站内**不得**赋予其姓名、设定、台词、身份。
- 关于页的对话气泡里是**站主的话**，不是角色的台词；气泡锚定在画面边缘，不指向画面内具体人物。
- 收藏页、相册页不出现角色化装饰。
- 简言之：**图里可以有人，站内没有角色。**

#### 3.5.7 C 级采集清单格式

交付为 `docs/ART-SOURCING.md`，每条：

```
### hero.webp
1. 作品名 / 作者 / 原帖直链
   推荐度：★★★
   理由：构图左空右实，暖粉天空，横构图 16:9 可裁
   建议裁剪：保留右侧 70%，左侧留白叠加标题
   下载后放置：public/art/hero.webp
2. …（至少 3 条）
```

我下载后放进目录，你执行：压缩转码 → 落位 → 登记 → 渲染校验 → 截图对比。

#### 3.5.8 登记与自动校验

`public/art/CREDITS.md` 字段：`文件名 / 作品名 / 作者 / 原作出处 URL / 许可类型 / 获取日期 / 来源级别（A/B/C）/ 备注`。

- 新增脚本 `scripts/check-credits.mjs`，并入 `npm run check`：**`public/art/` 与所有内容封面目录下每个图片文件，必须在 `CREDITS.md` 有对应条目，否则构建失败。**
- 部署后 `/credits` 页可点达每一条来源 URL。
- `/credits` 页底部保留固定声明，链接指向仓库 Issues，**不暴露任何个人联系方式**：

  > 本站插画版权归各原画师所有，仅作个人非商业展示，不提供任何形式的转载或商用授权。如您是权利方且不希望作品在此展示，请通过本仓库 Issues 告知，我会在 24 小时内移除。

#### 3.5.9 我自备图片的入口（与 agent 工作并行）

| 入口 | 用途 | 机制 |

| `public/art/` 同名覆盖 | 换成约稿图 / 我自己找的图 | 覆盖同名文件即生效，无需改代码；改完在 `CREDITS.md` 补一行 |
| `local-art/` | 本地预览用，不部署 | 已写入 `.gitignore`，build 时自动剔除 |

## 4. 页面与导航

### 4.1 导航

- **桌面端**：顶部居中悬浮胶囊（高 56px，`backdrop-filter: blur(14px)`，1px `--line` 边框，圆角 999px），滚动 200px 后加 `--shadow`。
- **移动端**：底部 Dock（`padding-bottom: env(safe-area-inset-bottom)`），最多显示 5 项，其余收进"更多"。
- **右侧固定**：主题切换（日/夜/跟随）+ 设置按钮（齿轮）。
- 导航项来自 `src/data/nav.config.ts`，每项含 `key / label / path / icon / visibleByDefault / group`。**设置面板里可以逐项勾选显示或隐藏**，写入 `localStorage`，刷新后保持。
- **默认只显示 5 项**：首页、文章、收藏、相册、关于。其余（工具箱、Now、素材来源）默认隐藏，在设置中勾选后出现。

### 4.2 页面清单

| 页面 | 路径 | 默认在导航 | 内容 |
|---|---|---|---|
| 首页 | `/` | ✅ | 见 §4.3 |
| 文章 | `/posts` | ✅ | 卡片瀑布流（1/2/3 列自适应），分类筛选：番剧 / 随笔 / 碎片 |
| 文章详情 | `/posts/:year/:slug` | — | 680px 单栏 + 右侧粘性目录（<1100px 隐藏）+ 顶部阅读进度条 + 文末 Giscus |
| 收藏 | `/favorites` | ✅ | 番剧 / 音乐 / 游戏 / 书 四个分区。番剧与游戏用贴纸卡（排版封面、评分、一句感想、状态标签）；音乐与书用列表行（名称、艺人/作者、外链、一句感想）。**不内嵌任何播放器或音频** |
| 相册 | `/gallery` | ✅ | 瀑布流 + 灯箱（键盘 ← → Esc 可操作），懒加载，EXIF 剥离 |
| 工具箱 | `/tools` | ❌ | 卡片网格，按分组（写作/设计/开发/生活）。**新增工具 = 在 `content/tools/` 加一个 md 文件，不需要改任何代码** |

| 素材来源 | `/credits` | ❌ | 见 §3.5.8，页脚小链接进入，`noindex` |
| 隐藏页 | `/secret` | — | Konami 秘技解锁，`noindex`，不在 sitemap |

**不做**：友链页、简历页、联系表单、留言板、AI 摘要、背景音乐、音乐播放器、音频文件、Live2D、3D、任何形式的联系方式展示。

### 4.3 首页结构（自上而下）

1. **主视觉**：全宽插画（日系清新，天空/房间/窗边），轻微视差 + 可选轻量粒子，底部渐隐入底色。插画上方压一行手写感大标题 + 一行 tagline（打字机，仅一次）+ 两个按钮：「读文章」「关于我」。右下角一个无文字的下箭头，缓慢上下浮动（只是视觉暗示，不做教程）。
2. **最新文章**：3 张卡片瀑布（不足 3 篇时用"收藏精选"补位，不允许出现空块）。
3. **收藏精选**：横向滚动条，4–6 张贴纸卡，移动端可横向滑动，桌面端显示 4 张 + "全部收藏 →"。
4. **相册条带**：一条横向图片带，缓慢自动滚动（`prefers-reduced-motion` 下停止）。
5. **一句话区**：居中，霞鹜文楷，一句站主自述 + 印章角标。
6. **页脚**：`© 2026 <昵称>` + 一句诗/彩蛋文案 + RSS 图标 + 素材来源链接 + 设置入口。**不放任何联系方式。**

### 4.4 响应式与设备适配（硬性要求）

必须覆盖并逐一验证以下断点：

| 断点 | 关键要求 |
|---|---|
| ≤ 375px（小屏手机） | 导航收进 Dock；正文 15px；卡片单列；主视觉高度 ≤ 60vh；按钮最小点击区 44×44px |
| 376–767px（手机/横屏） | 卡片 1–2 列；文章目录隐藏；表格可横向滚动 |
| 768–1023px（平板） | 卡片 2 列；导航仍为胶囊但去掉次要项 |
| 1024–1439px（笔记本） | 卡片 3 列；文章目录出现 |
| ≥ 1440px（桌面） | 内容最大宽度 1200px 居中，正文仍 680px |

另外必须处理：`safe-area-inset`（刘海屏）、`dvh` 替代 `vh`（移动端地址栏收缩）、横屏时主视觉不撑满全屏、iPad 触控下的 hover 状态不粘滞、`prefers-reduced-motion`、`prefers-color-scheme`、高 DPI 图（`srcset`）。

## 8. 工程与部署

- **仓库**：`用户名.github.io`，公开，`main` 为生产分支。
- **分支**：功能分支 + PR，合并前必须通过 CI（typecheck + build + link check + credit check）。**不允许直接推 main。**
- **提交信息**：Conventional Commits，中文描述，例：`feat(nav): 导航支持在设置中隐藏页面`
- **Actions**：`push → main` 时自动 `npm ci → npm run check → npm run build → upload-pages-artifact → deploy-pages`。
- **构建产物**：vite-ssg 预渲染所有路由；Pagefind 在 build 后生成索引；图片在 build 时转 WebP 并生成哈希文件名；`local-art/` 被排除。
- **404**：单独产出 `404.html`（含小游戏），GitHub Pages 自动使用。
- **SEO**：每页 `<title>`、`description`、`og:*`、`canonical`；`sitemap.xml` 与 `robots.txt` 自动生成；`/secret` 与 `/credits` 加 `noindex` 且排除在 sitemap 外。（Q102 选 A：只做基础 SEO，不做结构化数据）
- **RSS**：`/rss.xml`，包含最近 20 篇。
- **检查脚本**：`npm run check` = `vue-tsc --noEmit` + `eslint` + `prettier --check` + `linkinator` + `check-credits`。
- **备份**：README 中写明"建议本地 clone 一份"。
- **成本**：全免费。域名留空，先用 `用户名.github.io`。
- **打印样式**：`styles/print.css` 极简处理——隐藏导航/页脚/噪点/粒子，正文转黑白，链接后附 URL，页边距 20mm。
- **Dependabot**：开启，允许自动提 PR，但不自动合并。
